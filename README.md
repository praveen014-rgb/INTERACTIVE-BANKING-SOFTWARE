The Banking System Dissertation is a Java-based console application developed to
demonstrate fundamental banking operations. It allows users to either create new accounts
dynamically or work with predefined accounts, including single and double account modes.
The application provides essential features such as depositing money, withdrawing cash, and
checking account balances in a secure manner. In the double account mode, it also enables fund
transfers between two accounts, ensuring smooth and validated transactions. The system uses
a modular design with two classes: BankAccount for handling account details and operations,
and Main for user interaction and menu-driven control. It applies object-oriented programming
principles such as encapsulation, method abstraction, and data hiding to maintain clarity and
reusability. The use of Java’s Scanner class makes the program interactive by capturing user
input at runtime. It runs entirely in the command line environment without requiring external
dependencies, keeping it lightweight and portable. The dissertation highlights practical
programming concepts that are commonly applied in real-world financial applications.
